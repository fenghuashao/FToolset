# FToolset

## 简介

离线将当前网页、链接或文本生成二维码。支持自定义样式与中心图标，复制 PNG 或下载 PNG、SVG。

## 详细介绍

从 Chrome 工具栏打开 FToolset，把网页或一段文字做成可分享的二维码。

- 如果 Chrome 提供了当前网页链接，打开时会自动填入。也可以手动输入链接或文字、清空内容，或恢复当前网页链接。
- 右键点击链接或选中文字，从 FToolset 菜单直接生成二维码。
- 边编辑边预览。可选方形、圆点、圆角和复古码点，调整前景色、背景色及四档纠错等级。
- 可添加 PNG、JPG 或 SVG 作为中心图标，文件上限 4 MB、宽高各不超过 4096 像素。添加图标时，纠错等级自动切换到 H。
- 可复制 PNG 到剪贴板，下载 512 × 512 的 PNG，或下载可缩放的 SVG。

二维码生成、图标处理和导出均在本机完成。安装后可离线使用，无须账号，没有使用统计或上传。界面支持简体中文和英文，随系统切换浅色或深色外观。

支持 Chrome 111 及以上版本。如果右键操作后弹窗未自动打开，点击工具栏中的 FToolset 图标即可继续。
