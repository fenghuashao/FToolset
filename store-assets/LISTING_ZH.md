# FToolset

## 简介

离线二维码生成与识别、链接净化、文字整理字数统计与网页取色配色助手。本机运行、无需账号、零上传。

## 详细介绍

FToolset 将四款日常高频网页小工具收进一个轻量清爽的 Chrome 工具栏弹窗，帮助你离线处理网页链接、复制文字与屏幕配色，无需跳转杂乱的在线网站，也绝不上传任何内容。

- **二维码生成与离线识别**
  - 打开扩展即可自动填入当前网页链接（当 Chrome 授权读取时），也可手动输入或通过右键菜单将网页链接、选中文字直接生成二维码。
  - 支持方形、圆点、圆角、复古码点、自定义前景/背景色、四档纠错等级以及本机 PNG/JPG/SVG 中心图标（上限 4 MB、4096 × 4096 像素），一键复制 PNG 或下载 512 × 512 PNG 与可缩放 SVG。
  - 切至「识别」模式，支持 `Ctrl+V` 粘贴截图、拖入或选择本地图片离线解析二维码；识别到链接时仅在你主动点击后才打开。
- **链接净化**
  - 一键剥离当前网页、粘贴链接或右键链接中的常见追踪参数（如 `utm_*`、`fbclid`、`gclid`、`spm`、`si` 等），保留功能必需参数。
  - 清晰展示被移除的每一个参数，支持点击单项还原、复制干净链接，或一键转交二维码生成器制作更简洁的二维码。
- **文字整理与字数统计**
  - 实时统计总字符数、不含空格字数、词数、汉字数、段落数与预计阅读时长。
  - 一键清理多余空格、去空行、修复 PDF 复制断行、行去重与英文大小写转换，支持 10 步撤销与还原原文；网页划选文字后可右键直达整理。
- **网页取色与对比度检查**
  - 调用浏览器原生 `EyeDropper API` 吸取屏幕任意像素颜色，零额外权限，自动复制 HEX 并支持一键复制 HEX / RGB / HSL。
  - 内置黑白文字 WCAG 2.1 可读性对比度评估（`AAA / AA / AA 大字 / 偏低`），并在本机保存最近取色与收藏色板。
- **高效导航与大屏放大模式**
  - 默认单行 4 槽快捷栏随时切换，右上角「搜索」支持原地展开（`/` 或 `Ctrl/Cmd+K`）回车直达，进入「全部工具」可自由自定义固定项与排序。
  - 处理长文本或配色时，点击「放大」即可在独立新标签页以宽屏两列布局继续操作，并自动保留当前草稿。

所有处理均在浏览器本机离线完成，安装后断网可用，无需账号、无广告、无数据统计、无远程代码，也不使用云同步。界面支持简体中文与英文，自动跟随系统浅色/深色主题。

支持 Chrome 111 及以上版本。如果右键操作后弹窗未自动打开，点击工具栏中的 FToolset 图标即可继续。
