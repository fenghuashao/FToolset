# FToolset

## Short description

Generate QR codes from the current tab, a link, or text. Customize, copy, and export PNG or SVG entirely offline.

## Detailed description

Make a QR code from the Chrome toolbar and share a page or a piece of text as an image.

- Open FToolset to start with the current page's URL when Chrome makes it available. You can also enter a link or text, clear the input, or restore the page URL.
- Right-click a link or selected text and choose the FToolset menu command to use it as your input.
- Preview the QR code as you edit. Choose square, dot, rounded, or classy modules, set foreground and background colors, and pick one of four error correction levels.
- Add a PNG, JPG, or SVG as a center logo, up to 4 MB and 4096 × 4096 pixels. FToolset switches error correction to H when you add a logo.
- Copy the QR code as a PNG, download a 512 × 512 PNG, or download an SVG for scaling.

QR generation, logo processing, and export run on your device. FToolset works offline after installation and uses no account, analytics, or uploads. The interface supports English and Simplified Chinese and follows your light or dark appearance setting.

Requires Chrome 111 or later. If a right-click command doesn't open the popup, click the FToolset toolbar icon to continue.
