# FToolset

## Short description

Offline QR code generator & decoder, link cleaner, text cleaner, and screen color picker in your Chrome toolbar.

## Detailed description

FToolset brings four everyday offline utilities into one lightweight Chrome toolbar popup—so you can prepare web links, copied text, and screen colors without opening random websites or uploading your data.

- **QR code generator & decoder**
  - Opens with the current tab's URL when Chrome makes it available, or accepts manual input and right-click commands on links or selected text.
  - Customize dot style (square, dots, rounded, classy), colors, error correction, and a local PNG/JPG/SVG center logo (up to 4 MB and 4096 × 4096 px). Copy as PNG or download 512 × 512 PNG and scalable SVG.
  - Switch to **Decode** to scan QR codes offline from a pasted screenshot (`Ctrl+V`), dropped file, or local image. Decoded links only open when you explicitly click Open link.
- **Link cleaner**
  - Strips common tracking parameters (`utm_*`, `fbclid`, `gclid`, `spm`, `si`, and more) from the current tab URL, pasted links, or right-click links while keeping essential parameters intact.
  - Review every removed parameter, click any chip to restore it if needed, copy the clean link, or hand it straight to the QR code generator.
- **Text cleaner & word counter**
  - Live counts for characters (with and without spaces), words, CJK characters, paragraphs, and estimated reading time.
  - Clean extra spaces, remove blank lines, repair broken PDF line breaks, deduplicate lines, and convert English letter case—with 10-step Undo and Reset. Send selected webpage text straight from the right-click menu.
- **Screen color picker**
  - Sample any pixel on screen using Chrome's native `EyeDropper` API with zero extra permissions.
  - Copy HEX, RGB, or HSL in one click, check white/black text readability with WCAG 2.1 contrast ratios (`AAA` / `AA`), and keep recent picks and favorite swatches locally.
- **Fast navigation & full-tab workspace**
  - Jump to any tool from the customizable 4-slot quick bar or inline top-bar search (`/` or `Ctrl/Cmd+K`), manage pins in **All tools**, or click **Expand** to continue in a spacious full browser tab.

Everything runs locally on your device. FToolset works completely offline after installation, uses no account, analytics, remote code, or cloud sync, and supports English and Simplified Chinese in both light and dark modes.

Requires Chrome 111 or later. If a right-click command doesn't open the popup automatically, click the FToolset toolbar icon to continue.
